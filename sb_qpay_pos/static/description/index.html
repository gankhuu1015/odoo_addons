QPay POS Integration

POS дээр QPay төлбөрийн QR үүсгэж, төлбөрийг шууд баталгаажуулах модуль.

Odoo Enterprise болон Community хувилбар дээр ажиллана.

Зургийн жишээ

QPay тохиргоо

POS дээрх QR төлбөр

Үндсэн боломжууд

  • POS төлбөрийн дэлгэцээс QPay QR үүсгэнэ.
  • Төлбөр баталгаажихад POS захиалга автоматаар төлөгдсөн төлөвт орно.
  • Төлбөрийн дүн, баримтын дугаар, төлөвийн бүртгэл.
  • Татгалзсан/цуцлагдсан төлбөрт буцаах горим.

Тохируулахад шаардлагатай

  • QPay мерчант эрх (Client ID, Secret, API Endpoint).
  • Odoo POS тохиргоонд “QPay” төлбөрийн арга нэмэх эрх.
  • Интернэт холболт (POS төхөөрөмж).

Суулгалт

  1. Модулийг суулгана.
  2. POS → Configuration → Payment Methods хэсэгт шинэ төлбөрийн арга үүсгэнэ.
  3. “QPay” төрлийг сонгоно.
  4. QPay-ийн түлхүүрүүдээ оруулна.
  5. POS тохиргоонд уг төлбөрийн аргыг идэвхжүүлнэ.

Ашиглах заавар

  1. 1POS-д захиалга үүсгэнэ.
  2. 2Төлбөр хийх үед “QPay” сонгоно.
  3. 3QR код үүснэ.
  4. 4Хэрэглэгч банкны апп-аар QR уншуулж төлнө.
  5. 5Төлбөр баталгаажмагц захиалга “Paid” болно.
Зөвлөмж: Төлбөр амжилттай болсны дараа POS автоматаар баримт хэвлэнэ (POS тохиргооноос хамаарна).
